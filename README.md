# رزومه — ارسلان نوروزی

این مخزن شامل یک رزومهٔ ساده و حرفه‌ای به صورت **HTML و CSS** است.

## نحوهٔ نمایش محلی
1. فایل `index.html` را در پوشهٔ مخزن باز کنید.  
2. برای مشاهده در مرورگر، روی فایل دوبار کلیک کنید یا راست‌کلیک کرده و گزینه‌ی **Open with → مرورگر** را انتخاب کنید.  
3. اطمینان حاصل کنید که فایل `styles.css` در همان مسیر (`index.html` در کنار آن) قرار دارد تا استایل‌ها به‌درستی نمایش داده شوند.

---

. این رزومه شامل بخش‌های زیر است:
- اطلاعات تماس  
- خلاصه یا معرفی کوتاه  
- تحصیلات  
- تجربه‌ها و پروژه‌ها  
- مهارت‌ها  

---

. طراحی صفحه با HTML5 و CSS انجام شده است (بدون استفاده از JavaScript).
